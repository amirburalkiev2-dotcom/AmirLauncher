# AmirLauncher 1.5.4

Лаунчер Minecraft для себя: ванильные версии + сборки с Modrinth, офлайн-ник.

## Страница сборки
Клик по любой карточке сборки (или по «популярной сборке дня» на главной) открывает её страницу:
описание, скриншоты (с просмотром на весь экран), видео из описания, ссылки автора, выбор версии
Minecraft и версии самой сборки. Всё берётся с Modrinth. Видео открываются в браузере на YouTube.

## Рейтинг сборок
У Modrinth нет оценок игроков, поэтому рейтинг (от 1 до 5 ★) считает сам лаунчер по открытой статистике:
популярность (загрузки) — 35 %, подписчики — 30 %, вовлечённость (какая доля скачавших подписалась) — 20 %,
свежесть (как давно обновляли) — 15 %. Формула подобрана по 800 реальным сборкам Modrinth: топовые
получают 4.3–4.8, середина каталога ~2.7, никому не известные — ниже 2. Подписи: «Отличная» (4.3+),
«Хорошая» (3.6+), «Неплохая» (2.8+), «Малоизвестная» (2.0+), «Почти никто не пробовал». Рейтинг виден на
карточках, на главной и в шапке страницы сборки; на вкладке «Рейтинг и отзывы» — разбор по частям,
подписчики и ссылки на Discord и трекер ошибок автора. У сборок, импортированных из файла, рейтинга нет.

## Мои сборки
Слева — каталог (вкладки, поиск, «Фильтры»), справа — «Быстрые действия»:
- **Импорт** — установить сборку из файла `.mrpack`, `.zip` или `.rar` (см. «Импорт из архива» ниже);
- **Экспорт** — сохранить свою сборку в `.mrpack` для друга: список модов, настройки, ресурспаки, шейдеры,
  моды, добавленные вручную, и по желанию миры;
- **Редактировать** — переименовать, открыть папку, сменить версию (у своей сборки — редактор, см. ниже);
- **Папка игры** — открыть в проводнике папку, где лежит игра (там `instances` со сборками, версии и т.д.;
  то же есть в «Настройках»);
- **Удалить**.

Если установлено несколько сборок, лаунчер спросит, с какой работать.

### Импорт из архива (.zip, .rar)
Файл всегда проверяется: пути не должны выходить за папку сборки, ссылки (symlink) запрещены, размер после
распаковки — не больше 8 ГБ и 200 000 файлов, место на диске должно хватить. Что понимает лаунчер:
- **сборку Modrinth внутри архива** (`modrinth.index.json` в корне или во вложенной папке) — ставится как `.mrpack`;
- **экспорт MultiMC / Prism Launcher** (`mmc-pack.json`) — загрузчик и версия Minecraft берутся оттуда;
- **«готовую папку»** с `mods`, `config`, `saves`… (так часто раздают сборки, в том числе от TLauncher).
  Загрузчик и версию лаунчер определяет по файлам в `versions/`, а если их нет — по самим модам; перед
  установкой показывает окно, где это можно поправить. Файлы чужого лаунчера (`versions`, `libraries`,
  `assets`, логи, `.exe` и т.п.) не переносятся — Minecraft и загрузчик скачиваются заново, начисто;
- **сборку CurseForge** (`manifest.json`) лаунчер распознаёт, но поставить не может: в таком архиве нет
  модов, только их номера, а скачивать с CurseForge без ключа партнёра нельзя. Лаунчер предложит найти
  сборку на Modrinth.

Для `.rar` нужен **WinRAR** или **7-Zip** (бесплатный, 7-zip.org) — лаунчер найдёт их сам. В Windows 11
дополнительно пробуется встроенный `tar`. Если ничего нет, лаунчер скажет, что поставить.
Дополнительных `pip install` для `.rar` не нужно: чтение списка файлов (`rarfile`) вшито в `amirlauncher/vendor/`.

## Свои сборки
**«Создать сборку»** открывает окно «Создание новой сборки»: название (до 50 символов), обложка и логотип
(необязательно), загрузчик — Vanilla, Fabric, Forge, NeoForge или Quilt — и версия Minecraft (в списке только
релизы, которые этот загрузчик поддерживает; версия загрузчика берётся последняя стабильная). Сборка всегда
приватная — в лаунчере сборки создаются для себя, это не меняется.

После создания сборка появляется во вкладке «Установленные» (с логотипом — он же виден в «Выбрать сборку» на
главной). Настраивается она через ⋯ → **«Настроить сборку»** или «Редактировать» в быстрых действиях:
- **Моды, ресурспаки, шейдеры** — каталог Modrinth прямо в окне, у каждого проекта логотип. Показывается
  только то, что подходит к версии Minecraft сборки (моды — ещё и к загрузчику). Обязательные зависимости
  мода ставятся сами; при удалении мода убираются и зависимости, которые больше никому не нужны.
  Файлы проверяются по контрольной сумме Modrinth.
- **Карты** — на Modrinth карт нет, поэтому карта ставится из архива `.zip` (папка мира с `level.dat`);
  архивы с путями за пределы папки карты не принимаются.
- Там же можно переименовать сборку, сменить логотип и обложку, открыть папку.

Картинки своих сборок лежат в `~/.amirlauncher/custom/<сборка>/`, файл сборки — в
`~/.amirlauncher/packs/<сборка>-custom.mrpack` (по нему работает «Экспорт»).

## Запуск из исходников
```
pip install -r requirements.txt
python AmirLauncher.py
```

## Сборка в .exe (Windows)
Двойной клик по `build_exe.bat` → готовый файл `dist\AmirLauncher.exe`.
(То же вручную: `pip install pyinstaller` и `pyinstaller AmirLauncher.spec`.)

## Тесты и проверка кода
```
pip install -r requirements-dev.txt
python -m pytest tests          # интерфейсные тесты работают без окна и без интернета
ruff check .
black -l 120 --check .
```
Версии библиотек закреплены в `requirements.txt`. `minecraft-launcher-lib` — любая из ветки 8.x: всё, что
лезет в её внутренности (подмена загрузки установщика Forge ради запасного зеркала), собрано в
`mll_compat.py` и ставится по признакам, а не по номеру версии. Если библиотеку поменяли и признаки не
совпали, подмена просто не ставится — Forge качается обычным путём библиотеки, без зеркала, лаунчер не
ломается. `tests/test_install.py` проверяет, что на установленной версии подмена встаёт.

## Настройки
Файл `~/.amirlauncher/config.json` (создаётся сам). Полезное:
- `"links": {"telegram": "https://t.me/...", "discord": "https://discord.gg/...", "globe": "https://..."}` — кнопки в подвале главной.
- `custom_background.png/jpg` рядом с `AmirLauncher.py` (или exe) либо в `~/.amirlauncher/` — свой фон.
- Лог установки и ошибок: `~/.amirlauncher/install_log.txt`.
- `"jvm_args"` («Доп. аргументы Java» в настройках): если указать там свой `-Xmx` или `-Xms`, он заменит
  значение лаунчера, а не добавится вторым. Свой `-Xmx` важнее ползунка «Память».
- `"allow_unverified_mirror": true` — разрешить скачивать установщик Forge с зеркала (bmclapi), даже если
  его нечем проверить. По умолчанию выключено: зеркало используется, только если sha1 файла удалось
  получить с официального сервера Forge и он совпал.
